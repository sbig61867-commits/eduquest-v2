## الصفحات العامة

- **الطابع:** خلفية بيضاء، لون أساسي بنفسجي `#7C3AED`، أقسام تتناوب بين الأبيض والبنفسجي الفاتح جداً،
  أزرار بزوايا 12px، خط عربي خاص، توهّج لوني ناعم أعلى بعض الصفحات، قسم داكن واحد (المساعد الذكي).
- **ترتيب الرئيسية:** Hero (عنوان + زران + شارات + صورة لابتوب وجوال بلوحة حقيقية) ← لماذا سند (4 بطاقات)
  ← جولة في المنتج بصور شاشات ← المزايا (6 بطاقات مع كلمات مفتاحية) ← المساعد الذكي (داكن، محادثة توضيحية)
  ← لكل بيئة تعليمية ← **مستكشف الأدوار بتبويبات** (مدير/معلم/محاسب/ولي أمر) ← أسئلة قبل البدء ← قسم SEO محلي
  ← الأسعار وتكلفة الفروع ← الأسئلة الشائعة ← دعوة لعرض ← تواصل ← المدونة ← فوتر.
- **صفحات الحلول (5):** قالب واحد يتغيّر نصه حسب نوع المؤسسة.
- **المركز القانوني:** صفحة واحدة تجمع الشروط والخصوصية والأمان والاسترداد والكوكيز وSLA كبطاقات.
- **الدخول:** بطاقة بيضاء في المنتصف، تبويبان (الموظفين / أولياء الأمور)، زر عريض، «تذكرني».

## لوحة الإدارة الداخلية

- **الهيكل:** قائمة جانبية يمين (شارات أعداد)، شريط علوي (الفرع، بحث، إشعارات، وضع داكن)، وعلى الجوال
  شريط سفلي بخمس أيقونات.
- **نمط ثابت لكل قائمة:** أزرار إجراءات ← 4 بطاقات أرقام ملوّنة ← فلاتر ← جدول بشارات حالة.
- **الرئيسية:** بطاقات أرقام هي روابط إلى ما يحتاج إجراء (طلبات معلّقة، غائبون اليوم، حضور غير مسجّل) + اختصارات.
- **مساحات العمل:** كل قسم صفحة أدوات مع «جميع الأدوات (70)» و«المفضلة» وبحث، وبطاقة «خطوتك التالية».
- **الفصول:** بطاقات (اسم، معلم، عدد طلاب) بأزرار سريعة بدل جدول.
- **الحضور:** تسجيل جماعي بارز + بطاقات حاضر/غائب/متأخر.
- **الجدول الأسبوعي:** أعمدة أيام وبطاقات حصص.
- **التقارير:** فلاتر + ملخص + جدول نسب + تصدير PDF/Excel/طباعة؛ ملخص الطلاب حسب الحالة/الصف/الحلقة/الفرع.
- **مركز SMS:** بطاقات (مُرسل، اليوم، انتظار، فشل)، حملات/قوالب/سجل، قوالب جاهزة (غياب، تأخر، رسوم، ترحيب)،
  متغيرات تُدرج في النص، فلاتر جمهور تفصيلية (فرع، صف، شعبة، حالة، جنس، عمر، متأخرو الرسوم، الغائبون بتاريخ).
- **رسائل الأهالي:** محادثات بعمودين (مثل واتساب ويب). **الإشعارات:** بطاقات بإطار ملوّن حسب النوع.
- **الإعدادات (28 أداة):** إعداد المؤسسة وقائمة جاهزية، سياسة التقييم وخطط توزيع الدرجات وفترات التقييم،
  الصفحة العامة لكل مؤسسة (شعار، نبذة، رسالة، رؤية، رابط خاص)، تطبيق الموبايل (الأجهزة والجلسات)،
  إعدادات المساعد الذكي، سجل النشاطات، المستخدمون (صندوق شرح أعلى الصفحة)، المستندات، الاستيراد، الدعم الفني
  (حالات: جديدة، مفتوحة، قيد المعالجة، تنتظر ردك، محلولة، مغلقة)، الاشتراك والفواتير، الدليل، ما الجديد.
- **حماية الاستيراد:** يشترط اختيار فرع محدد قبل استيراد Excel.

## نقاط ضعف نتجنبها

- قائمة جانبية بأكثر من 20 عنصراً وأقسام متداخلة.
- صفحة إعداد المؤسسة مزدحمة بالنصوص.
- البنفسجي لون شبه وحيد، فتتشابه الصفحات — ميزتنا: التصميم الأبيض 1 متعدد الألوان (نيلي + برتقالي + أخضر + سماوي).

## ميزات مقترحة لـ Tilmoo (بالأولوية)

1. **«خطوتك التالية»** للطالب والمعلم (أكمل الدرس 3، عندك اختبار غداً، تسليمات بانتظار التصحيح).

5. **جلساتي وأجهزتي** (Better Auth يوفر الجلسات).

7. دليل مدمج + «ما الجديد؟».
8. سياسة تقييم لكل مؤسسة (درجة النجاح، الأوزان).
9. مكتبة ملفات للمؤسسة (Cloudflare KV).
10. تذاكر دعم من المؤسسة إلى المشرف العام (امتداد لنظام الطلبات الحالي).
11. شريط تنقّل سفلي على الجوال للطلاب.
12. مستكشف أدوار بتبويبات + صفحات حلول لكل نوع مؤسسة + مركز قانوني موحّد في الموقع العام.
